HEM IMMOBILIER — Prévisualisation de refonte

Ouvrir index.html dans un navigateur. Tous les fichiers HTML sont dans ce dossier.

Les photos sont des extraits de la maquette fournie (la qualité dépend de cette capture). Pour une mise en production, remplacer ces extraits par les photos originales en haute résolution avec les droits nécessaires.
Les annonces sont statiques et ne sont pas synchronisées avec le site officiel. Les formulaires utilisent mailto: ; aucun backend n’est inclus.
Le barème des honoraires et les biens vendus sont liés au site d’origine plutôt que reproduits sans données fiables.

Pour publier une prévisualisation : déposer le contenu de ce dossier sur GitHub Pages ou un hébergement statique.

Animations : les sections, titres, cartes et boutons apparaissent progressivement au défilement.
Les photographies de la page biens à vendre proviennent des URL officielles de hem-immobilier.fr et nécessitent une connexion Internet.
